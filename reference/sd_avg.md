# Calculate average standard deviation

Averages the standard deviations of two groups (square root of average
variance).

## Usage

``` r
sd_avg(sd1, sd2)
```

## Arguments

- sd1, sd2:

  standard deviations of the first and second group.

## Value

the average standard deviation

## Examples

``` r
sd_avg(5, 3)
#> [1] 4.123106
```
